# Tutorial da API USP Graduação

Bem-vindo ao tutorial da API USP Graduação! Este guia foi elaborado para ajudar novos usuários a entender e utilizar a API de forma prática e eficiente.

## Introdução

A API USP Graduação é uma API REST desenvolvida com FastAPI que permite gerenciar registros de imóveis em diferentes áreas de cidades. Com esta API, você pode criar, buscar, atualizar e excluir registros de forma simples através de requisições HTTP.

Neste tutorial, você aprenderá como:

1. Instalar e configurar o ambiente
2. Criar e gerenciar o banco de dados
3. Iniciar a API
4. Fazer requisições para criar, buscar, atualizar e excluir registros

## Para quem é este tutorial?

Este tutorial é destinado a:

- **Estudantes** que estão aprendendo sobre desenvolvimento de APIs com FastAPI
- **Desenvolvedores** que precisam utilizar a API USP Graduação
- **Administradores** responsáveis pela manutenção da API

## Pré-requisitos

Antes de começar, certifique-se de que você tenha:

1. Python 3.12 ou superior instalado
2. PostgreSQL 12 ou superior instalado e em execução
3. Conhecimentos básicos de linha de comando e APIs REST

## Como usar este tutorial

Recomendamos seguir os tutoriais na ordem apresentada, especialmente se você é iniciante. Cada seção foi projetada para se basear no conhecimento adquirido nas seções anteriores.

Se você já tem experiência com APIs e apenas precisa de informações específicas, sinta-se à vontade para pular diretamente para a seção relevante.
